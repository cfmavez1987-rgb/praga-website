# Проект ПРАГА — Контекст для другого ИИ-агента

## Обзор проекта

**ПРАГА** — это магазин разливного пива и закусок в городе Актау, Казахстан. Проект включает:

1. **Маркетинговый сайт** (`/website/`) — лендинг с информацией о магазине
2. **Мобильное веб-приложение (PWA)** (`/app/`) — каталог товаров, корзина, заказы, админ-панель
3. **Нативные мобильные приложения** (`/android/`, `/ios/`) — обёртки над PWA через WebView
4. **SMM материалы** (`/smm/`) — контент для социальных сетей

---

## Технологии

| Компонент | Технология |
|-----------|------------|
| Сайт | HTML/CSS/JS (одиночный файл `index.html`) |
| PWA приложение | HTML/CSS/JS + Firebase SDK 9.23.0 |

| Хостинг PWA | Netlify (`https://praga-webapp.netlify.app/`) |
| Мобильные приложения | Android (Java WebView) / iOS (Swift WKWebView) |

## Важные замечания для следующего агента

1. **Не менять дизайн-систему** — цвета и шрифты уже согласованы с заказчиком
2. **Валюта — тенге (₸)**, не рубли
3. **Firebase используется для хранения товаров** — не localStorage
4. **Изображения сжимаются** перед отправкой в Firebase (400px, JPEG 0.6)
5. **Сайт и приложение — разные сущности** с разным функционалом
6. **Админ-панель встроена в PWA** — отдельного файла нет
7. **Номер WhatsApp placeholder** — нужно заменить на реальный при необходимости
