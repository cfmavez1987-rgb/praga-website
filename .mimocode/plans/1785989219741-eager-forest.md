## Что нужно сделать

### 1. Добавить `netlify.toml` для автодеплоя PWA

Создать `/Users/batime/Desktop/Project/praga-mobile/netlify.toml`:

```toml
[build]
  publish = "app"

[[redirects]]
  from = "/*"
  to = "/app.html"
  status = 200
```

Это направит Netlify на папку `app/` с `app.html` как главной страницей.

### 2. Обновить код на Netlify

После добавления `netlify.toml` — закоммитить и запушить. Если Netlify подключён к GitHub, деплой запустится автоматически.

Если Netlify настроен вручную — нужно перезадеплоить через Netlify Dashboard:
- Site settings → Build & deploy → Trigger deploy

### 3. Проверить работу

После деплоя проверить:
- https://praga-webapp.netlify.app/ — товары загружаются
- Корзина работает
- Админ-панель доступна (admin/12345)
- Настройки показывают поля логина/пароля
