# ПРАГА — Магазин разливного пива и закусок

## Структура проекта

```
├── website/          # Сайт-визитка
│   ├── index.html    # Главная страница
│   ├── images/       # Изображения напитков
│   ├── Friends_clinking.mp4  # Видео для.hero
│   └── start.sh      # Скрипт запуска сервера
│
├── app/              # Мобильное приложение (PWA)
│   ├── app.html      # Приложение
│   ├── manifest.json # Манифест PWA
│   └── images/       # Изображения напитков
│
├── smm/              # SMM-план
│   └── smm-plan.md   # Стратегия продвижения
│
└── README.md         # Этот файл
```

## Как запустить

### Сайт
```bash
cd website
python3 -m http.server 8888
# Открыть http://localhost:8888
```

### Приложение
```bash
cd app
python3 -m http.server 8888
# Открыть http://localhost:8888/app.html
```

## Функции

### Сайт
- Hero секция с видео фоном
- Пузырьки с изображениями напитков
- Переключатель языка (RU/KZ)
- Адаптивный дизайн

### Приложение
- Каталог товаров
- Корзина и оформление заказов
- История заказов
- Профиль пользователя
- Авторизация и регистрация
- Админ-панель с дашбордом

## Технологии
- HTML5, CSS3, JavaScript
- PWA (Progressive Web App)
- LocalStorage для данных
